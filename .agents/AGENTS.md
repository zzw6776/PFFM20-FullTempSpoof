# Workspace Rules

- 常规构建、测试和 APK 安装直接执行，不打开用户可见的 macOS Terminal 窗口；可在当前任务中等待完成并直接报告结果。
- 前一条所称“常规测试”不包括耗时实机脚本。实机脚本只要满足任一条件：预计可能超过 30 秒、包含循环/等待/重试、串行运行多个阶段或持续输出进度，就默认视为需要用户观察，必须在用户可见的 macOS Terminal 中启动；只有用户明确要求后台执行时才可例外。无法判断是否命中时按命中处理；可见 Terminal 不可用时应先告知用户，不得静默改为后台执行。
- 启动上述实机脚本前必须确定唯一进程（或锁）和唯一日志文件。若脚本已经在后台启动，禁止重新启动；只能在可见 Terminal 中跟随同一份日志。
- 等待上述实机脚本期间，助手不得使用 `write_stdin`，也不得反复轮询进程、日志或状态。应暂停操作并等待用户告知脚本结束，再读取一次最终日志并继续处理。
- 打开可见 Terminal 不会扩大操作授权；安装、刷写、应用补丁、重启等动作仍必须严格遵守用户明确给出的范围。
